# Repository instructions

This repository demonstrates a small, portable toolkit for authoring agent
skills.

- Canonical examples live in `.agents/skills/<skill-name>/SKILL.md`.
- Keep examples generic and independently written.
- Never add employer material, private data, credentials, or copied local
  instructions.
- Keep synchronization in dry-run mode unless a person explicitly supplies
  `--apply`.
- Run `pnpm check` before committing.
